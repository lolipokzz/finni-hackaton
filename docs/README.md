# Документация проекта «Питомец Финни»

Сопроводительная документация к прототипу (ТЗ, раздел 5). Ссылки вида **ТЗ 2.5.6** указывают на пункты
технического задания Департамента финансов города Москвы (2026). Где что лежит по пунктам ТЗ —
в [08 — Матрица требований](08-requirements-matrix.md).

## Состав

| Файл                                                   | Что внутри                                                                                                                     |
|--------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------|
| [01-product-overview.md](01-product-overview.md)       | Что делаем, для кого, принципы, роли, что запрещено, глоссарий, минимальный объём контента, сквозной сценарий                  |
| [02-domain-model.md](02-domain-model.md)               | Модели игры и питомца, их поля, инварианты, формат сохранения                                                                  |
| [03-processes.md](03-processes.md)                     | Бизнес-процессы шаг за шагом: первый запуск, игровой период, покупка, накопления, задания, итоги, раздел взрослого, демо-режим |
| [04-rules-and-formulas.md](04-rules-and-formulas.md)   | Все числа и формулы игровой экономики в одном месте: баланс, план/факт, состояние и рост питомца, срок достижения цели         |
| [05-content-model.md](05-content-model.md)             | Учебный контент (задания, приключения, товары, цели, питомец, тексты): где лежит, как проверяется, как добавить задание |
| [06-architecture.md](06-architecture.md)               | Пакеты и слои, игровой движок, хранение, потоки, ViewModel, навигация, 3D-питомец, разрешения, сборка релиза, тесты                |
| [07-screens.md](07-screens.md)                         | Список экранов, что на каждом обязательно видно и можно сделать, правила UX для детей                                          |
| [08-requirements-matrix.md](08-requirements-matrix.md) | Матрица соответствия ТЗ → экран/модуль/тест со статусами                                                                       |
| [09-test-cases.md](09-test-cases.md)                   | Тест-кейсы ключевой логики и сценария демонстрации                                                                             |

| [11-economy.md](11-economy.md)                         | Предложение: экономика на вырост, категории магазина, ценовая политика и прогон стратегий ребёнка                              |

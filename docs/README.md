# Документация проекта «Питомец Финни»

Рабочая документация для команды разработки. Источник требований — техническое задание
Департамента финансов города Москвы (2026), копия текста лежит в
[reference/tz-2026.md](reference/tz-2026.md). Везде ниже ссылки вида **ТЗ 2.5.6** указывают на
пункты этого документа.

## Правила ведения документации

- Любое изменение чисел экономики делается сначала в [04-rules-and-formulas.md](04-rules-and-formulas.md), потом в `content/config.json`, потом в тестах.
- Новый экран или процесс сначала описывается здесь, потом реализуется. Матрица требований обновляется в том же PR.
- Термины используем строго по глоссарию из [01-product-overview.md](01-product-overview.md#глоссарий): один термин — одно имя класса.

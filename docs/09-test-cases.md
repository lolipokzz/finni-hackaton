# 09 — Тест-кейсы

Три уровня:

1. **Unit-тесты** (`app/src/test/`, 177 тестов) — автоматические, без эмулятора. Основное покрытие для **ТЗ 3.4**
   «логика бюджета, списания, накоплений и прогресса покрыта автотестами». Запуск:
   `./gradlew :app:testDebugUnitTest`, отчёт — `app/build/reports/tests/testDebugUnitTest/index.html`.
2. **Тесты контента** — те же unit-тесты, которые проверяют минимумы ТЗ 2.6 и целостность контента.
3. **Ручной E2E-прогон** обязательного сценария на физическом устройстве перед каждой сдачей, с записью результата в
   таблицу в конце файла.

Все числа — из [04](04-rules-and-formulas.md).

## E2E: обязательный сценарий

Прогоняется вручную на физическом устройстве (Android ≥ 8, ОЗУ ≥ 3 ГБ) перед каждой сдачей. Шаги 1–3 — на чистой
установке, дальше — в демо-режиме: «Настройки» → «Для взрослых» → пример → «Включить демо». Ожидаемые числа — при
точном следовании шагам.

| Шаг ТЗ | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Установить APK, запустить | Экран знакомства с Финни за ≤ 5 с; уроки о трёх решениях: обязательное, необязательное, копилка |
| 2 | Пройти знакомство | Нигде нет полей для реального имени, телефона, e-mail |
| 3 | Выбрать раскраску, имя «Финни», закончить знакомство | Главный экран: питомец нужной раскраски, 50 монет, «В копилке 0», «Цель не выбрана» |
| 4 | Включить демо, вернуться на главный | «Финни Демо», 50 монет, неделя 1, активное задание — приключение «Первый поход в магазин»; в «Заданиях» все 6 заданий доступны |
| 5 | «План недели»: 20 / 15 / 15, остаток 0, «Начать неделю» | Монеты 35, в копилке 15 (строка «Копилка» ушла сразу) |
| 6a | Задание «Что купить первым?» → «Купить шляпу, еда подождёт» | Объяснение ошибки, +3, монеты 38; в демо задание можно сразу решить ещё раз |
| 6b | То же задание → «Купить еду, а на шляпу копить» | Объяснение, +5, монеты 43, задание выполнено |
| 7a | Магазин → «Овощи» 10 → купить, ещё раз «Овощи» | Окно покупки показывает категорию, цену и «Финни получит»; монеты 23, сытость 100 |
| 7b | «Лимонад» 10 → купить | Монеты 13, настроение 60, по плану на необязательное осталось 5 |
| 7c | «Кепка» 40 → купить | Окно «Не хватает 27 монет» и «Что можно сделать» (заработать на задании, подождать новую неделю…); взять из копилки не предлагается — там 15, меньше недостающего; баланс 13 не изменился |
| 8 | Копилка → цель «Кроватка» 60 → отложить 5 | «Осталось 45 · примерно 3 нед.» до пополнения; после — копилка 20, монеты 8, «Осталось 40 · примерно 2 нед.» |
| 8′ | Задания → приключение «Первый поход в магазин», пройти без ошибок | +5, монеты 13 |
| 9 | Главный экран | Монеты, копилка, цель, сытость и настроение; «Дела недели» 4 из 4 |
| 10 | «Дела недели» → «Завершить неделю» | Итоги: 4 дела, бонус копилки +5 (копилка 25), настроение 45, сытость 65, карманные +50 → монеты 63; неделя 2, снова план |
| 10′ | Ещё неделя со всеми делами (план, еда, отложить, приключение, завершить) | 8 шагов роста → «Финни подрос!», подросток, карманные 60 |
| 11 | Свернуть, закрыть приложение из списка недавних, запустить | Главный экран с теми же значениями |
| 12 | «Для взрослых» → пример → «Сбросить демо» → подтвердить | «Финни Демо», 50 монет, неделя 1; «Сбросить профиль» и «Удалить все данные» ведут на знакомство |

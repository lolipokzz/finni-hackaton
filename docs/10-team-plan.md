## Definition of Done для задачи

- Поведение описано в `docs/` (или PR правит docs), матрица требований обновлена.
- Для правил игры: unit-тест на успешный и отклонённый путь.
- Для экрана: проверен на 360×640 и при шрифте 200 %, все нажимаемые элементы ≥ 48 dp, тексты для ребёнка — из
  контента (`feedback.json`, `data/content/`) или экрана, не из `domain` и ViewModel.
- `./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug` зелёный.
- Ни одного числа экономики вне `GameRules`, моделей питомца и контента.

## Git

- Ветки от `master`: `feature/<область>-<кратко>`.
- Мелкие PR, ревью второго участника обязательно для моделей игры и API движка.
- Секреты и `*.jks` не коммитим (`.gitignore`).

## Известные ограничения прототипа (ТЗ 5.11)

- Один профиль на устройство.
- Контент (задания, приключения, товары, цели) описан Kotlin-списками, а не JSON-файлами: добавление задания не
  трогает логику, но требует пересборки ([05](05-content-model.md#дальнейшее-развитие)).
- Ежедневного бонуса и начисления баллов родителем нет: доход — только карманные, задания и приключения.
- Непредвиденные расходы показаны только сюжетом приключения «Лапка», отдельных событий недели нет.
- Планшеты и альбомная ориентация не проверялись, приложение работает в портретной ориентации.
- Только русский язык.
- Первый показ 3D-питомца после запуска зависит от компиляции шейдеров на устройстве (на эмуляторе ~3 с).
- «Кот повторяет слова» работает только при выданном доступе к микрофону и не распознаёт речь — только меняет голос.

## План развития

1. Перенести контент в JSON-файлы `assets/content/`, чтобы менять задания без пересборки.
2. Несколько профилей и отчёт для взрослого по неделям.
3. События недели с непредвиденными расходами и «подушкой безопасности».
4. Ещё задания и приключения по каждой теме, выбор сложности.
5. Поддержка планшетов и альбомной ориентации, английская локализация.
6. Публикация в RuStore после проверки с детьми (с согласия законных представителей, **ТЗ 8.4**).
